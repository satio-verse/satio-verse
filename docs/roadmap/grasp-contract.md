# 物体中心、接触点与附着变换的统一契约

2026-10-28，书架交互复核后的设计与实施记录。**契约基础已实现；真实取读还未通过，默认关闭，仅 `surfacegrasp=1` 开启实验。** 现状、失败证据与回归见 [第三批记录](foundation-batch3.md)。下文的全程身体约束和多形象验收仍是待完成目标。

## 已核实的问题

`web/locomotion.js` 的 `_palmHold` 用手腕到中指根的 0.6 处，加掌心法线方向的 `item.half + 0.012`，预测物体中心。`desktop/web/room-props.js` 的 `_inHand` 又按 0.55 处、最薄边的一半加 4 mm，并沿长边偏移来摆可见 GLB。GLB 物件的代理没有一起采用这份变换。因此动作的目标、诊断中的中心、画面中的书不是同一份状态。

只读检查的 `IR_Item_Library_01` 是平移节点，局部尺寸约为 X 0.298 m、Y 0.238607 m、Z 0.054802 m；朝房间的外侧为 +X。局部 X 约 0.14 m 的表面锚有望缩短伸手距离，但仍须检查网格、遮挡和手指空间。不能把最长轴自动认作所有书的书脊。

`room-afford.js` 阅读分支还会直接把 `item.held` 从 right 改为 left；当前可见物体没有完整的双手交接约束。相邻采样帧位移包含真实运动、重定向和换手影响，不能直接把它全部称为瞬移。

## 状态与数学关系

保留物体的真实中心、姿态、尺寸与支撑高度。`half` 目前还参与落地/台面高度计算，不能为了手握得近而减小它。新增接触元数据也不能改变 `home.place = center.y - supportHalf` 的含义。

采用列向量约定，`T_A_B` 将 B 坐标映射到 A 坐标。对显式配置的物件定义局部抓取变换 `T_object_grasp`（局部接触点、法线、切向），手定义对应的 `T_hand_grip`。接触成立时：

```
T_world_object * T_object_grasp = T_world_hand * T_hand_grip
T_world_object = T_world_hand * T_hand_grip * inverse(T_object_grasp)
```

上式是理想接触目标。实际通过容差后，绑定保存 `inverse(T_world_palm_actual) * T_world_object_actual`，以后用实际掌心乘这份绑定；因此不会在接触帧把残余误差用物体瞬移消掉。持物后的附着一致性不能反过来当作抓取前已经接触的证据。

IK、代理物体、可见 GLB 和接触误差都从这条关系派生。节点原点不一定是包围盒中心，GLB 的原始局部偏移和初始朝向必须保留。`Props` 对采用此契约的物体只同步完整变换，不再用另一套手心公式改位置。

第一版仅标注经核实的书，不自动覆盖杯子、球或刚体抓持。物理书要另接 Rapier 的局部抓持锚与姿态目标后再加入。

## 行为阶段

1. **选择抓法与站位**：以可接近的表面锚规划手，检查手臂可达、身体与转向空间；手可以进入书架隔板的空隙，头不能穿入实体部件。失败必须保留失败原因，不用增大误差容忍让流程通过。
2. **靠近与接触**：物体保持原世界姿态；手到接触容差内才绑定。保存当帧相对变换，禁止在绑定瞬间改用陈列姿势。
3. **持物与阅读**：目标姿态连续变化。首个版本可让这类书从开始就用空闲左手；左手占用时明确返回不可用。需要换手时，先让接收手接触同一物体，再转移附着关系，清理旧侧交接状态；禁止直接改 `held`。
4. **归还与释放**：使用原始中心、原始朝向和同一接触锚。位置、方向和支撑条件成立才解除附着；不能在松手瞬间强行重置朝向或把物体吸回原位。

## 实施边界

- `room-props.js`：读取明确的抓取元数据，统一可见物体/代理变换；保留未接入物件的原分支。
- `locomotion.js`：`pick/put`、`_holdTarget/_wristFor`、`_items/_palmHold`、释放判定共用物体与抓法信息，不能在函数传递中退化为只有 `{half}`。
- `room-acts.js`：保存归还的原始姿态；`room-afford.js`：传入抓法/首选手，移除该物件的裸换手。
- 感知层仍只接收观察和动作后果。内部碰撞/控制真值不能直接变成她已经知道的房间知识。

## 验收与研究有效性

新“掌心到表面锚”误差与旧 `grabGap` 并列记录；旧值是代理中心口径，不能改定义后宣布它下降。额外记录可见中心与代理中心偏差、抓取/释放/换手两侧的世界姿态连续性、末端接触误差、手臂可达性和最终头部碰撞。

验收必须完成真实取读还，拒绝动作不算防撞成功。覆盖书的位置/朝向、三形象、两种家具布局、不同拿取侧与不可达情形，并保留球和杯子的回归。当前小屋使用真实帧间隔，固定种子并不保证轨迹相同；先做固定步长与状态复位的集成驱动，再把结果用于自动调优或论文中的量化收益。

在契约统一前，不把书的接触误差交给参数搜索或模型训练来弥补；否则可能奖励代理坐标正确、画面或物理不正确的策略。
