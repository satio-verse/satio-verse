# 路线: 一个实时闭环基座, 两个验证场

WorldModel v1 的核心资产不是某个模型, 而是一条被埋点反复测量的实时闭环:

```
说完 -> 端点 -> 意图闭合 -> 动作开始 -> 声音发出 -> 面部/身体跟着声音
       (状态: 角色在哪、坐着站着、手里拿什么; 记忆: 关于用户的事和关系)
```

同一个闭环, 先在虚拟本体 (VRM 角色) 上把"陪伴"做到可信, 再换执行器落到仿真/物理本体上. 两个验证场共用一套
意图协议 (`do/side/to/amp/spd/at` + 置信度), 互相喂数据: 陪伴场的交互数据和语义动作给具身场当"人类演示";
具身场练出的物理可行性和运动策略反过来提升陪伴场的动作自然度.

小窝的可供性 (房间里的东西能拿来干什么, 她看见了才知道、试过才知道好不好; 看书、浇花、开关灯、擦洒出来的…): [room-afford.md](room-afford.md), 2026-10-27 方案和第一批.

轻量动作生成模型 (MB 级、浏览器实时, 借 ARDY 和 Learned Motion Matching 的思路, 让"说一句就生成"新动作): [motion-model.md](motion-model.md), 2026-10-27 R0 (资料、许可盘点、基线), R1 等用户确认.

原则:
- 每加一个模块都用同一套埋点量它对延迟的影响 (说完->听到声音 P50/P95), 不退化才合入.
- 许可从第一天起按商用标准选: 非商业的组件 (HAST-SEC、BEAT2 衍生、AMASS/SMPL 系) 只作对照或临时占位, 并标明替换路径.
- 新下载一律先列名称、来源、大小、许可, 确认后再下.
- 路线文档里引用的外部工作, 标了"待核实"的只在用户提供的材料里出现过, 还没看到原文或代码.
