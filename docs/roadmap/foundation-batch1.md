# 基础修复第一批：动作验收与工作台

2026-10-28。状态：源码和离线验证完成；正式服务未重启，没有启用候选、训练或修改动作执行算法。

## 为什么先做这一批

E18 已说明“多个种子”可能只覆盖一个拿起片段；旧验收还可能在基础参数、动作库或验收算法变化后继续被复用。工作台则漏算思考、工具参数等上下文，大文件后部读取存在空结果错误，Search 费用归入了不同于工作台 LLM 的分类。这些问题会影响后续研究结论与成本判断。

## 已实现

- **Gate v3**：记录实际片段标识/顺序、完整姿态轨迹摘要、运行模式和帧数；分别报告种子数、轨迹摘要去重数、片段数。默认拿放与显式拿球场景要求覆盖 `cmu69_68_pick`、`cmu69_69_pick`，按片段分组的退步不能被总均值掩盖。
- **固定样本分组**：验证 `[3,4,5,11]`、确认 `[6,7,8,9]`，默认训练仍为 `[1,2]`。旧清单合并新要求；已知训练、验证、确认种子冲突明确拒绝。每次仍检查实际覆盖，不把种子表当成覆盖保证。
- **验收证明绑定**：核对验收清单、参数、代码/评估器、出厂参数、形象与动作库资产、实际基础槽位；检查期间发生变化也拒绝。旧证明需重核，不能在采用时给它补一个当前指纹。成功重验会清除旧队列项。
- **完整请求计量**：预算和实际发送共用消息构造，统计 `messages + tools` 的规范化 JSON 字符量，含完整思考、工具参数、背景和结构。120k 为整理软阈值，不是 token 上限或模型窗口。
- **配对整理**：仅缩短较早且完整配对的工具结果，保留调用关系、完整思考及最近历史；无可整理内容时如实标记超阈。前端显示字符数与“整理阈值”，兼容旧服务字段。
- **大文件分页**：支持任意行、超长行字符续读和有界读取；新增 `char_offset`，返回续读位置。小文件原格式兼容，`web_fetch` 原有 find/锚点/缓存未改。
- **费用归属**：新 Search 费用统一计入 `agent`；历史账本、价格配置不变。

## 边界与下一批
