# 阶段一: 陪伴场 (虚拟本体) — 进度与待办

目标: 让角色从"会聊天、会做动作的程序"变成"可信的陪伴者": 动作自然不穿模、记得你、知道自己有多确定、
说话时身体和语音韵律一致, 并开始积累"做了什么 -> 对方怎么反应"的数据.
