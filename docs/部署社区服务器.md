# 社区服务器部署（自建源）

客户端本身不需要公网服务器：她在本机跑，插件与更新是「拉」不是「推」。但要让别人**发现和更新**插件、以及让应用检查新版本，需要一台公网机放两样东西：

1. **插件索引与包**（`tools/community_server.py`，默认 8792 端口）
2. **更新清单**（`/releases/*.json`，纯静态文件）

## 一、机器与网络

- 一台 Linux 云主机（2C2G 起步够用；4C8G 能同时跑索引 + 镜像），域名一个子域（例：`community.example.com`）。
- 开 443，用 certbot 申请证书；nginx 直接照抄 `deploy/nginx-platform.conf.example`（已带 `limit_req` 30 r/m 与 `/releases/` 静态别名）。
- 数据目录建议 `/srv/worldmodel-data`：`store/`（包）、`private/`（作者表与签发密钥）、`releases/`（更新清单）。**只把 `store` 的索引与包、`releases` 的 JSON 暴露出去，`private/` 永远不要 alias。**

## 二、一条命令（推荐）

机器是空的 Ubuntu/Debian、DNS 已经把域名指过来的前提下，root 跑：

```bash
curl -fsSL https://raw.githubusercontent.com/Tanora001/satio-verse/main/deploy/bootstrap.sh -o /tmp/bootstrap.sh
sh /tmp/bootstrap.sh satio-verse.gitgratitude.com
```

它会装包、拉代码、建数据目录与密钥、起 systemd、配 nginx、最后用 certbot 签证书。幂等，可以重复跑。

## 三、手动起服务

```bash
# 1) 准备
python3 -m venv /srv/wm-venv && /srv/wm-venv/bin/pip install -r deploy/requirements-platform.txt
mkdir -p /srv/worldmodel-data/{store,private,releases}
head -c 32 /dev/urandom | base64 > /srv/worldmodel-data/private/receipt-secret.txt   # 回执签名密钥
echo '{}' > /srv/worldmodel-data/private/authors.json                                   # 作者 token 表：sha256(token) -> 稳定作者 ID

# 2) 起（前台试跑一次，确认 /index.json 200）
sh deploy/start-platform.sh /srv/worldmodel-data https://community.example.com /srv/wm-venv/bin/python

# 3) 常驻：systemd 单元（示例）
# [Service]
# WorkingDirectory=/srv/satio-verse
# Environment=WM_RECEIPT_SECRET_FILE=/srv/worldmodel-data/private/receipt-secret.txt
# ExecStart=/srv/wm-venv/bin/python tools/community_server.py \
#   --home /srv/worldmodel-data/store --authors /srv/worldmodel-data/private/authors.json \
#   --public-url https://community.example.com --port 8792
# Restart=always
```

接口（都在 `tools/community_server.py` 里）：`GET /index.json`、`GET /packages/{name}`、`POST /packages`（要作者 token）、`POST /contributions`（收投稿）、`DELETE /contributions/{id}`。

## 四、客户端怎么接

工作台「市场」→ 添加源（填 `https://community.example.com/index.json`）→ 刷新。装包前会先出**装前报告**（世界种类、前缀、动作/事件、四档权限、告警），导入后默认停用，显式启用才跑。包校验走 sha256 + `{worldmodel_package:1}` 格式，见 `wm/platform_services.py`。

## 五、更新清单

`/releases/latest.json` 是一个静态 JSON：

```json
{"version": "0.2.0", "published": "2026-11-23", "notes_url": "https://github.com/Tanora001/satio-verse/releases/tag/v0.2.0",
 "assets": [{"os": "windows", "url": "https://community.example.com/releases/satio-verse-0.2.0-win.zip", "sha256": "..."}]}
```

客户端只**提示**，不自动替换（`update_trust` / `update_apply` / `update_rollback` 是显式动作）。签名与回滚策略还没定，见下一节。

## 六、还没做的（上线前必须补）

## 七、国内用户的下载源

短期：**GitHub Releases 主源**（`https://github.com/Tanora001/satio-verse/releases`）+ 这台机反代一份到 `/releases/`。GitHub 在国内不稳定时，客户端读第二个源的 `latest.json` 即可（多源在 `CommunityStore` 里已经支持）。
