# 工作台升级：嵌套任务、工具侧栏与可部署平台

本轮在原有工作台上接入真实运行接口，保留桌宠、会话、材料、成果和既有权限配置。

## 从哪里使用

- **会话列表**：父会话下面展开嵌套子会话。点击进入独立记录，从顶部返回主会话；完成结果以折叠卡片汇回主会话。
- **每条消息下方**：复制、回答反馈、从该消息分支、时间。分支只带走选中位置以前的记录。
- **右侧“Agent 与嵌套任务”**：手动按行拆分任务，选择读取、共享工作区或独立 Git 工作树；查看任务树与预设。并行设置默认折叠，超出并发数的任务排队。
- **Agent 预设**：标准、计划、创造、研究；可新建、编辑自定义指令及工具清单。预设决定工作方式，实际权限仍取自会话。
- **右侧“工作区文件”**：目录浏览、Markdown/文本预览、命令输出和停止。命令是独立 PowerShell 进程，暂不是持久交互终端。
- **右侧“工具与上下文”**：查看当前真正可用的工具、压缩上下文、搜索和分页读取原始记录；进入扩展、数据贡献和更新。
- **“生活与成长”**：读取真实运行参数、预览修改、应用、查看采用证据和历史、恢复。改变被调度器读取，不等于某次自主活动已成功执行，两者分别展示。
- **插件社区**：浏览本地或配置的公共索引，导出 Creator 包，配置作者服务后发布。大型模型和语音组件仍由独立组件页管理。

## 执行和上下文

子任务拥有独立会话与上下文，支持递归委派、排队、取消、结果回报。共享工作区不会隔离文件写入；同时修改相同代码应选 Git 工作树，工作树中的修改仍需检查和合入。

新的工具输出会保留原文，模型使用精简视图，需要时可搜索读取。历史版本中已经丢弃的内容无法凭空恢复。界面中的上下文字符计数用于压缩阈值，不冒称精确 token 数，也不会把模型窗口直接变成 1M。

完全授权模式下，渠道不再额外要求逐条草稿审批，也不再套用固定的每日/连续未回复次数上限。用户明确设置的对象范围、黑名单、暂停和预算仍生效；平台连接错误与服务侧限制仍会真实报告。升级不替用户改变既有授权或自动发布新的内容。

## 数据、社区和更新

诊断统计、训练对话分别选择，默认关闭。当前实现支持预览脱敏、加入待上传、手动提交、撤回和远程删除收据；没有自动上传全部历史记录，也没有实际训练流水线。

没有公网服务器时，社区与数据接收端保持待部署状态，插件仍可导出为本地包。交付的 `platform-deployable.zip` 包含服务、作者初始化、依赖、Windows/Linux 启动脚本、HTTPS 示例、更新及签名工具，不含用户数据和密钥。完整步骤见 [部署说明](platform-publishing.md)。

网页资源与插件支持验证后在空闲时应用、重新打开界面，并可回滚。后端、EXE、DLL 更新先暂存，退出后离线替换并重启；当前未实现宿主自动下载、退出、替换、健康检查的完整无人值守更新器。大组件不走小补丁通道。

内置浏览器支持可嵌入网页、隔离的文字阅读和外部打开。拒绝嵌入的网站需要使用后两种方式；当前不是拥有独立标签进程和完整登录兼容性的原生浏览器。
