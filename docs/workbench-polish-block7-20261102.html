她能写 Word、做 PPT 了

新工具，走本机装好的组件
  • docx_create：大标题、小标题、段落、圆点 / 编号列表、引用、表格，一块一块写成一份 Word
  • docx_read / docx_edit：按"第 N 段"读、改写、在后面加一段、删一段，段落样式不变；改之前原件存一份到工作区的 .archive/office-时间/
  • pptx_create：封面 + 一页一个标题、几条要点、备注
  • office_to_pdf：经本机 Word / PowerPoint 另存成同名 PDF
  • 都只写工作区里的文件，和"写文件"一样过守门和黑名单；写出来的登记成这一轮的成果（下面两张卡片）

网页引用回到原处

滚到引的那几句
  • 网页里选几句引用时记下那几句；点卡片回去时，原生网页跳到 网址#:~:text=那几句（浏览器内核自己滚过去、标黄），文字阅读里滚到含那几句的那一段，找不到再回到那一节
  • 长的取开头一小句和结尾一小句当起止；测试里核对了宿主收到的导航网址（原生网页的滚动和标黄要在桌宠窗口里看）
