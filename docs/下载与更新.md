# 下载、更新、装插件

## 一、下载

| 渠道 | 地址 | 说明 |
|---|---|---|
| GitHub Releases（主） | https://github.com/<org>/satio-verse/releases | 每版附源码 zip 与便携包 |
| GitHub Pages（备） | https://<org>.github.io/satio-verse/ | 下载页 + 插件目录镜像 |
| 自建镜像（国内加速） | 维护者部署，域名见 Release 说明 | 内容一致，签名校验后可互换 |

解压即用，不需要安装器：

```bash
unzip satio-verse-v0.1.0.zip -d satio-verse && cd satio-verse
python -m venv .venv && . .venv/Scripts/activate
pip install -r requirements.txt
python -m wm.services up
```

不想装本地模型：把 config/local.json 的引擎切成 mock，界面与流程照样跑通。

## 二、更新

1. 客户端启动时读 https://api.github.com/repos/<org>/satio-verse/releases/latest，只提示「有新版本」，**不自动替换文件**。
2. 手动更新：下载新 Release → 覆盖程序目录 → 保留 config/local.json 与记忆库不动。
3. 数据库/房间格式变更会写进 CHANGELOG 与迁移说明。

## 三、装插件（在线）

插件 = 一个目录 + wmworld.json（世界插件）或 SKILL.md（能力扩展）。

**从市场装（推荐）**：打开桌宠 → 工具 → 市场/数据大盘 → 点「装前报告」
（显示会加哪些动作、发哪些事件、要哪些权限、要不要联网）→ 报告无「错」才允许「确认导入」；
装进来的插件默认**停用**，需要手动启用。

**命令行**：python -m wm.plugin_cli install <包路径或 URL>（若该入口存在），
安装逻辑在 wm/agent/install_gate.py：先校验契约（inspect），过了才写盘；
世界插件交给 wm/agent/plugin_host.py 落地，默认权限档 text。

## 四、自己写插件 / 加组件

1. 复制 plugins/ 下的样例（如 plaza-2d）
2. 写 wmworld.json：id、name、plugin{schema:2, version, tier, permissions, panel, world{...}}
3. 自检：python -m wm.agent.plugin_manifest <目录>；pytest -q tests/test_plugin_manifest.py
4. 上官方目录：向 satio-plugins 仓库提 PR，CI 跑同一套契约校验

世界接入四个接点：wm/world/（规则与权威状态）、web/physics/（碰撞）、
web/scenes/room.json（房间 DSL）、wm/world/economy.py（市场与账本）。

## 五、哪些不该提交

.gitignore 已排除：models/、runtime/、logs/、backups/、character_models/、config/local.json。
