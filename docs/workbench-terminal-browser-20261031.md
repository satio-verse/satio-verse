# 工作台终端与浏览器：使用说明及发布记录

2026-10-31（用户当地日期）。本轮已更新本机正式版本：真实 PowerShell 终端、独立原生网页面板、可选的安全审查预设，以及分栏与窄窗口修复。它们接入现有工作台和会话，不需要另开一套 DSH。

## 如何使用

| 功能 | 入口和行为 |
| --- | --- |
| 打开终端 | 工作台右侧“终端”，或 `Ctrl + 反引号`；点击“新建”启动当前工作区的 PowerShell |
| 多终端 | 同一聊天可新建多个独立终端；顶部切换，选项中重命名 |
| 持续运行 | 目录、变量、交互输入和进程保留；收起面板或刷新前端后可重新连接 |
| 中断与关闭 | `Ctrl+C` 或“中断”打断当前命令；“关闭会话”结束该终端及其拥有的子进程 |
| 查找与导航 | `Ctrl+Shift+F` 搜索输出；`Ctrl+Shift+↑/↓` 跳转提示符；可复制选中内容、清屏 |
| 状态与主题 | 显示等待、运行、完成、失败、退出码及程序上报进度；提供午夜紫、松林绿、暖纸白主题 |
| 后台通知 | 在终端选项中主动开启；隐藏终端有重要状态变化时通知，点击回到所属聊天和终端 |
| 浏览网页 | 右侧“浏览器”，输入网址、关键词或 BV 号；支持前进、后退、刷新、停止、收藏及把链接添加到当前聊天 |
| 阅读模式 | 可切换简化阅读；系统浏览器入口用于下载等当前面板未覆盖的操作 |
| 调整分栏 | 拖动聊天和工具面板之间的分隔线，宽度会保存；窄窗口自动收起导航，放大后恢复可读布局 |
| 安全审查 | Agent 预设选择“安全审查”；随附技能可在技能设置中发现并绑定到人设 |

## 实现范围

终端使用 Windows ConPTY 与本地 xterm.js，不是每次执行一条命令后退出的文本框。控制序列支持 OSC 133 提示符、OSC 7 目录、OSC 7501 状态、OSC 9;4 进度，以及基础 OSC 9 / 777 / 99 通知。OSC 99 的完整协议和全部 Shell 尚未覆盖；本轮提供 Windows PowerShell。前端刷新可重连，**后端退出或电脑重启不会恢复运行中的进程**。输出是有限滚动缓冲，不是无限日志存档。通知也仍需应用运行和浏览器授权。

终端属于人直接操作的本机 Shell，沿用会话归属和明确的权限规则检查；它不是对每个键入命令进行 AI 审批或操作系统沙箱隔离。只读、计划、归档会话与明确禁止终端的规则不会被新入口绕过。

浏览器使用单独的 WebView2 环境和 `browser-data` 用户目录。网页按顶层页面加载，不再依赖嵌入 iframe；不会获得工作台的设置桥、文件代理或宿主对象。对应用服务端口的隔离覆盖请求、重定向和 Service Worker。具体接口与实现见 [原生网页面板](workbench-native-browser-20261031.md)。当前是**一个原生网页面板**，并非完整多标签浏览器；设备授权和自动下载暂未集成。需要近期 WebView2 Runtime，旧运行时会显示明确错误。

“安全审查”预设只改变任务工作方式，保留现有权限和人设。Xsdsh-purge 依赖 DSH/Cordis 的宿主与界面接口，本轮没有安装它、复制其实现或内置反编译器。已完成的参考核验、兼容性及能力差异见 [参考核验记录](terminal-browser-reference-20261031.md)。

复现入口：`tests/test_agent_terminal.py`、`tests/test_agent_security_review.py`、`tools/test_native_browser.py`；界面驱动及独立服务 fixture 保存在证据目录的 `interaction-check.cjs`、`fixture.py`。原始输出和最终截图在 `E:/WorldModel-terminal-browser-20261031/`，其中 `interaction-results.json`、`regression.log`、`native-browser-11/native-result.json` 是相应最终记录。
