怎么看到：在工作台窗口按 F5（或等顶栏冒出"有新版本 · 刷新"点一下），不用重启服务端。

能力与插件：先放真开关

学 DSH 的插件页
  • 内置能力三张卡：子智能体（同时跑几个、最多套几层，存到服务端；以前藏在协作任务页最底下）、联网搜索（这个会话开不开，和输入框底下的地球是同一个设置；新会话默认 跟着当前会话 / 默认开 / 默认关）、终端（每条命令默认等 60 秒、最多 600 秒，输出最多 2 万字——这两个数写在程序里，照实写成说明，不做假开关）
  • 已安装：扩展一行一个，右边是开关（启用后她马上能用，"技能"里会多出它）；技能、MCP 工具服务只列出来，在设置里管；"版本与回退"跳到扩展与版本页
  • 页头"添加插件"：在聊天里让她做 / 添加 MCP 服务器 / 新建技能 / 从本地装工具与内容包 / 插件市场 / 插件社区——每一项都是现成的真入口
  • 原来页头的四个按钮挪成标题下面一行"也在这里"；原来的全部能力列表放在最后

扩展：打开就生效

重开页面还在
  • 打开"纪要格式（验收）"，下面"技能"里马上多了它（扩展里的）；刷新工作台再打开插件页，开关还是开着；关掉，技能也跟着没了
  • 操作提示条贴在面板底边（以前页面一长，提示条会压在内容中间）

添加插件

一项两行：做什么 + 在哪儿做
  • "在聊天里让她做"把话填进输入框（不直接发）；其余几项打开设置里对应的那一页或插件社区

Agent 预设：做成卡片

说明 · 怎么用 · 用这个
  • 一张卡一种工作方式：说明、"怎么用"一句、"用这个"；正在用的那张描主色；最后一张虚线框"让她帮我设计一个"（在聊天里开始 / 自己填）
  • "用这个"照旧改这个会话的预设，顶栏立刻显示（比如"计划"）
