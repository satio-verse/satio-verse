工作台精修清单

第六轮 · 2026-11-01 · 照 Codex、Linear、Notion、ChatGPT 的优点细修。截图都是改前，来自测试服务端（假模型、临时数据），点图能放大。

先给你看：点头以后按批动手，每批做完都给你看改后的样子

规矩

  • 借的是布局和交互，不搬别家的图标、标志和名字；界面里的图标还是我们自己的线条图标。
  • 只改工作台的前端；桌宠自己的设置窗口、/mail 页面（读邮箱那边的会话负责）、后端接口都不动；不用重启服务端。
  • 每批做完：跑界面测试（现在 65 项，新东西加进去），出改前 / 改后对比截图，写进知识库；你在工作台按 F5 就能看到。

四家各学什么

Codex骨架

左栏的项目和会话、右侧多标签、改动卡。已经照着做了，这轮补细节：标签栏、代码着色。

Linear密度和细节

列表一行一项、分组带数量、统一的按钮和字号；悬停才出的操作、快捷键提示、命令面板。

Notion空间和资料

置顶、最近访问、属性行、Markdown 和表格排版；资料本怎么分组、加标签、拖进来。

ChatGPT对话和引用

来源胶囊和来源列表、操作行放在哪、文件小卡、首屏输入框和建议胶囊。

现在

  • 新页面（对话、面板）和老页面（工具页、任务与成果）是两套样子：字号、圆角、按钮各不一样，有的按钮还是浏览器默认的灰框。

  • Linear交互细节：图标按钮悬停出"名字 + 快捷键"；列表能用 ↑↓ 和 Enter；悬停、按下继续用你定的橙黄。

动：workbench-shell.css（变量和公共样式），老页面的 css 改成引用这些变量

2

对话页

第一批中间的主区

现在

  • 网址做成整张大卡片（每张约 58 px 高，带"打开方式"），两条网址就占一大块，正文被冲散。
  • 复制 / 赞 / 踩 / 分支 / 时间这行夹在网址卡片和改动卡中间，看着像只管上半截。
  • 表格是粗边框格子；"本轮执行结束 · 1 轮 · 4 步 · ¥0.00"单独一行，和头部"已完成 · 2 秒"重复。

借鉴

  • ChatGPT来源：正文里的网址换成站点名小胶囊，悬停出标题；一轮末尾一个"来源 2"按钮，点开在右侧面板列出全部来源，"打开方式"挪到那里。
  • ChatGPT操作行放在整轮最后；最新一轮常显，旧的悬停才出。
  • Codex改动卡保留，固定在正文后面。
  • Notion表格：表头浅底、细横线、圆角外框，太宽就横向滚动。
  • Linear步数、花费并进头部右边的灰字，悬停看明细。

改成：顺序固定为「过程摘要 → 正文 → 改动卡 → 来源 → 操作行」。

动：workbench.js（turnCards、linkCards、herHead）、workbench-shell.css

输入框

第一批底部的输入区和它的菜单

现在

  • 提示语很长："给绫音发消息，拖入文件或粘贴图片也行（输入 / 看指令）"。
  • 下面一行一直挂着：工作区 / 此计算机 / Enter 发送 · Shift+Enter 换行 / 1 轮 · 上下文 2.1 万字。
  • 权限菜单每项两三行说明，扫一眼找不到在选什么；"自动执行"是橙红色，像报错。

借鉴

  • ChatGPT提示只写"给绫音发消息"；加进来的文件是带类型图标的小卡，图片出缩略图。
  • Codex底栏只留工作区和运行位置；上下文用量做成小圆环，悬停看数字；快捷键说明收进悬停提示。
  • Linear菜单一项一行（图标 + 名字 + 右边的勾或快捷键），说明只在悬停或选中时展开。

改成：提示语缩短、底栏瘦身、权限菜单一行一项，只有"完全授权"用提醒色。

动：workbench.html、workbench.js、workbench-shell.css
