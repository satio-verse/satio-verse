录之前看一眼
  • 在安静的小房间里录：关窗、关风扇和空调；屋里软东西多回声就小，对着挂满衣服的衣柜录最好。
  • 从头到尾用同一个话筒、同样的距离：嘴离话筒 10–20 厘米，稍微偏开一点，免得喷麦。
  • 按下录音后停半秒再开口，说完停半秒再按停止（录音会自动多留一点前后的空白）。
  • 像跟朋友说话一样，用你平时的语速和语气，别用播音腔。读错了就整句重录，别留着。
  • Windows 的"音频增强"、QQ 和微信的降噪会改你的声音，录之前关掉；这个页面自己已经关了回声消除、降噪和自动音量。
  • 每录 20–30 分钟歇一下、喝点水；感冒或嗓子哑的时候别录。四次最好在一两天里录完。
  • "参考音"那几句会在合成时当样子用，用你最想要的语气读；"考卷"那些句子用来测语音识别认你认得准不准。
录音只存在这台电脑上，不会上传。全部录完后在项目目录运行 python tools/voice_record.py prepare 整理成训练集， python tools/voice_record.py asr-test 测语音识别。
