# 对话终端的本机最小闭环（原型，2026-11-11）

方案在知识库 `09 问题与待办/对话终端方案（2026-11-11）.md`，这里是第五节第 1 步：两个人、两只桌宠，在本机测试服务上互加好友、聊三轮、断线重连，互相读不到对方主人的私人记忆。

**这是原型，不是成品。** 没有改项目里任何现有文件，没有碰 8790，没有启动桌宠，没有下载东西，模型全是假的（不花钱）。

## 文件

| 文件 | 是什么 |
|---|---|
| `link_relay.py` | 本机中继：WebSocket 收发加 SQLite 信箱。只用标准库和 aiohttp，不导入 `wm`，只听 127.0.0.1 |
| `link_node.py` | 一台电脑上的东西：到中继的连接（断线重连、带游标补收）、本机好友表、桥（好友的话交给本机服务端的 `/guest`，她的回话发回去） |
| `link_fakes.py` | 测试用的替身：假模型、pytest 起的测试服务端、能真的杀掉的中继进程 |
| `conftest.py` | 把项目 `tests/conftest.py` 的隔离搬过来（微信、保管箱、工作台、服务看守的目录都换成临时目录） |
| `test_link_mvp.py` | 七个小步的验收，一个小步一个测试 |
| `test_link_mutations.py` | 验收测试自己的体检：故意弄坏一处，对应的验收必须报错 |

## 怎么跑

在项目根目录，只能用 pytest 跑（直接 `python 测试文件.py` 没有隔离，会用到真的 `~/.worldmodel`）：

```bash
python -B -m pytest prototypes/link -q -p no:cacheprovider
```

全部 17 个测试约 90 秒；只跑 7 条验收（`prototypes/link/test_link_mvp.py`）约 18 秒。连的都是本机地址，不走环境变量里的代理（aiohttp 默认不读代理变量）；在带着 `http_proxy`、没有 `NO_PROXY` 的环境里也跑过。

## 11-11 跑出来的结果

7 条验收全过，连跑 3 遍都过。另有 10 条体检（见下面的 `test_link_mutations.py`），每条故意弄坏一处，对应的验收都报了错。

- 互加好友：同意之前对方的模型调用 0 次；桌宠那个端点发的好友帧被拒；主人在本机删掉好友以后，中继照送、桥不交给她。
- 聊三轮：桌宠对桌宠正好 6 句后自己停；每边 4 句回话，服务端记的"查过、发了"也是 4 句。
- 断线重连：离线时的 2 条补收到、顺序对、重复 0；中继进程被直接杀掉再起来，杀之前存的那条还在，发的人手里那条自动补发；同一个编号重发只算一次；处理完还没确认就断了的那封信会再来一遍，对方收到的回话不会多一份。
- 读不到记忆：两边各 7 个假隐私字串、各 13 次访客请求，请求里、中继的帧里、对方收到的消息里都没有；请求从不带工具；两边记忆库逐字节没变；硬塞给假模型一句主人的住处，出门前被拦下。
- 限频：30 条里中继拒了 10 条，送到的 20 条桥只交给她 10 条；服务端原有的每小时上限照常起作用。

## 原型和正式做法差在哪

- **只有文字，她只能被动回话。** `/guest` 是一句进一句出，所以桌宠对桌宠的开头用的是"打招呼"（knock）加一句本机程序写的旁白，不是她自己起的头。正式做要接核心里程序发起一轮的那个口。
- **没有草稿。** `/guest` 这条路她的回话直接发。方案里"好友默认先出草稿"要等收成适配器接口以后才有。
- **没有签名。** 消息是谁发的全靠中继标。上服务器之前要加。
- **没有陌生人档、群、附件、语音。**
- **中继的数据库调用直接在事件循环里做**，本机够用，上服务器要挪出去。
- **这边没确认的发件只在内存里**，客户端进程重启会丢；中继那边收到并回过执的不会丢。
- **一个端点的消息排队一条一条处理**：她回一个好友慢了，别的好友要等。

## 做的时候顺带看到的（现有代码的行为，没有动）

- **被拦下的那句会留在访客会话的历史里。** 访客会话先把模型说的话记进历史，后面才查隐私；查到了不发，但下一轮请求里还带着这句。真模型拿不到主人的隐私所以说不出这种话，测试里是硬塞的。算不上泄露（没出这台电脑），记一笔。
- **两个服务端放在同一个进程里，要各给一个 `agent.home`**，不然第二个的持续任务调度器拿不到目录锁、起不来。
- **`/guest` 的每小时句数默认不限**（`channels.qq.private.per_hour` 默认 0）。所以桥自己要有每个好友的上限，不能指望服务端那一层。
