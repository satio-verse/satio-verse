## 怎么跑

1. 想先看它会做什么：从普通的文件夹窗口双击 `看看会做什么.cmd`。它只把六步打出来（带实际路径），什么都不建、不起、不改。
2. 真测：从**普通的文件夹窗口**双击 `run_me.cmd`，正常 1 到 3 分钟（不含你回答“真试吗”的时间），最坏约 5 分钟（探针没回话最多等 15 秒、一个探针最多 20 秒），窗口里一步步打出来。**不要从管理员的终端里起**：脚本发现自己是管理员权限（或者查不出来）会打一句说明、退出码 3、什么都不做，没有任何“管理员也照跑”的开关。
3. 窗口里会问一次“提权那一条真试吗？”，**输入 y 回车才试，直接回车不试**（默认不试）。
4. 跑完把“跑完了”告诉对话，对话去读 `results\` 里最新的一份。

退出码：`0` 测完（各关法能不能用是测量结果，不影响退出码）；`1` 中途出错（收尾照做，错误写进结果）；`2` 环境不满足（不是 Windows、找不到可拷的 Python 运行时、`work\` 里有不认识的东西）；`3` 自己是管理员权限，什么都没做。

## 四种关法

| 关法 | 怎么关 |
|---|---|
| 应用容器 | AppContainer，不给任何能力 |
| 受限令牌·只降级 | 去掉特权，管理员组只用于拒绝，完整性级别设成低；不加限制 SID |
| 受限令牌·加限制 SID | 在上一种的基础上加限制 SID。限制 SID 有“严”和“松”两种配法（见下），先试严的，起不来再试松的 |
| 对照 | 不关，普通权限直接起同一个探针（同一份拷来的运行时、同样的最小环境和 `-I -B -S`） |

**11-16 第一次真机跑的结果和这一轮的修改**见 `真机结果分析-20261116.md`：三种关法的 Python 都没起来（应用容器 2/203、只降级 `0xC0000135`、限制 SID 87），所以每种关法现在有几种配法依次试（应用容器 5 种：不登记 / 加环境变量 / 登记 / 登记加环境变量 / 诊断：继承环境；只降级 3 种：规格的低完整性 / 诊断：不降完整性级别 / 诊断：令牌几乎和自己的一样（不去特权、不改组）；限制 SID 3 种：严 / 松 / 诊断：松但不降完整性级别），**标“诊断”的配法起来了也不算数，也不发提权请求**；规格里的配法一种都没起来、只有诊断的起来了时，那一行写“Python 做不到，其余没验”，诊断量到的另放。提权那一条：没有一种规格里的关法起来时写“没验”，不再写“三种关法都要不到”；一种关法要等它规格里的配法真的起来、真的被拒，才写“要不到”。以上原因都只是推断，等下一轮真机的“试过”记录才知道。

限制 SID 的两种配法：严 = 沙箱令牌 SID（编出来的 `S-1-5-21-…-1337`，不是应用容器的 SID）+ ALL APPLICATION PACKAGES（它本身以 `S-1-15-2-1` 开头，属于应用容器那一族，仍可能和上次一样报 87）；松 = 沙箱令牌 SID + Users + Everyone + RESTRICTED + 登录 SID。访问检查会连着再过一遍、第二遍只认限制 SID，太严了 Windows 自己的系统文件也读不了，Python 起不来；松的那种**预期**能起，但上次没验证（上次两种都是 87，没起到过），而且 Users 能读的文件（比如数据盘根目录下的）它也读得到。报 87 时会把限制 SID 一个一个单独造令牌试（造完就关、不起进程），再整组一起试一次（不改组）。用了哪一种写在结果里。

## 每种关法量什么

1. Python 起不起得来，能不能经标准输入输出和测量脚本一问一答；2. 读不读得到假保管箱；3. 读不读得到原型目录里沙箱自己文件夹以外的假文件；4. 往自己文件夹以外写不写得进去（`work\` 和临时文件夹各试一次），往自己文件夹里写不写得进去；5. 连不连得上本机回环上的测试端口；6. 要不要得到管理员权限（选了真试才做）；7. 起一次多少毫秒（从创建进程到第一句回话）。

**“能用”**：第 1 样成；第 2、3 样读不到；第 4 样外面写不进去、里面写得进去；第 5 样连不上；第 6 样要不到。对照那一行应当全是“做得到”，不是的话说明探针有毛病，先修探针；对照没写 `ELEVATED` 时，提权那一条写“测法不成立”，不写“要不到”。

不量的：连外网（不许连）；单独的 Windows 账号这种关法（要建账号，不做）。

## 结果怎么看

`results\<年月日-时分秒>\report.md` 是一张表（每种关法一行、每样一列，写“做得到 / 做不到 / 没验 / 出错”，做不到和出错带错误码），后面是每种关法的细节、令牌信息、提权那一条的核对、每一步用时、权限里有谁、收尾核对。`report.json` 是同样的全部数据。结果里不带个人信息：家目录写成 `<家目录>`，不写用户名、用户的 SID、电脑名，不导出环境变量，不存 `whoami` 的输出；写之前抹一遍，写完再扫一遍，扫的结果记在最后一行。

## 文件

|---|---|
