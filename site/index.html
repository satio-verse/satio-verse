S.A.T.I.O VERSE · 本地优先的角色外壳

一个住在你电脑里的角色。房间、声音、记忆都在本机。

3D 客厅、发光的对话胶囊、记事与日程，都是自带的。模型跑在本机，密钥不出门；没装模型时用 mock 顶上，先把界面走通。

01世界

打开就是一间 3D 客厅。

角色站在房间中间，底部那颗发光的胶囊就是输入框：打字、语音、贴一张图都从这里进。房间、家具、灯光都是场景数据，可以换成别的。

02能力

装好之后，这些是现成的。

01

对话

一个输入框接文字、语音和图片。语音走本机 TTS，字幕和表情跟着这一轮的内容变。

02

记忆

记事、日程、关系存在本地，换一个模型接进来，这些还在。

03

能力

技能和工具用同一份 schema 描述，权限分四档。装之前先看清单，装完默认是停用的。

04

世界

房间和街区可以换，家具、角色、道具按清单进场。能改的东西归服务器，渲染归客户端。

05

数据

插槽、记忆、市场都在大盘上，接口只读。想知道它现在什么状态，看接口就行。

06

插件

加社区源只要一行地址。每个包自带装前报告，写清它要动哪些文件、要哪些权限。

04开始

从 clone 到打开窗口。

需要 Python 3.10 或更高。没有显卡、没下模型也能起，会退化成 mock，先看界面和流程。

  1. STEP 01

    拉代码

    git clone https://github.com/satio-verse/satio-verse cd satio-verse
  2. STEP 02

    装依赖

    python -m pip install -r requirements.txt
  3. STEP 03

    起服务

    python -m wm.services up # 然后打开 http://127.0.0.1:8790/pet/satio.html
