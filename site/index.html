01世界

不是聊天窗口，
是一间能走进去的屋子。

推门进去是黄昏的客厅：沙发、电视、书架、窗外那点将暗未暗的光。她站在中间；底下那颗发光的胶囊，就是说话的地方——打字、开口、丢一张图都行。

02能力

六件事，
都长在同一个内核上。

01

对话

一条胶囊接住文字、语音和图片。字幕跟着她的情绪走，语气、停顿、亮度都能调。

02

记忆

记事、日程、关系都存在本机。换个模型接进来，它照样认得你。

03

能力

技能与工具走同一份契约，权限分四档。装之前先看清单，装完默认停用。

04

世界

房间与街区可以换，家具、角色、道具按清单进场；能改的东西归服务器，好看的东西归客户端。

05

数据

插槽、记忆、市场全在大盘上，接口只读。想知道她在想什么，看编码就行。

06

插件

社区源一行地址就能加；每个包带装前报告，告诉你它要动哪些东西、要哪些权限。

04开始

三步，
她就到你家了。

需要 Python 3.10 以上。没有显卡、没下模型也能先跑起来——它会退化成 mock，先把界面和流程走通。

  1. STEP 01

    拉代码

    git clone https://github.com/satio-verse/satio-verse cd satio-verse
  2. STEP 02

    装依赖

    python -m pip install -r requirements.txt
  3. STEP 03

    起服务

    python -m wm.services up # 然后打开 http://127.0.0.1:8790/pet/satio.html
